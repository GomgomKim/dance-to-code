# 💃 dance-to-code

웹캠 앞에서 춤 동작을 하면 코드가 입력되고, 점프하면 실행되는 웹앱.
인스타 릴스 촬영용으로 만들었습니다. 포즈 인식은 [MediaPipe PoseLandmarker](https://ai.google.dev/edge/mediapipe/solutions/vision/pose_landmarker)가 **브라우저 안에서** 돌고, 백엔드는 없습니다 (카메라 영상은 어디로도 전송되지 않음).

```
🙌 → 👉 → 👈 → 🙅 → 🙋 → 🚀(점프)
console.log("Hello World");   ▶  Hello World 🎉
```

## 로컬 실행

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # 포즈 분류기 / 수기신호 / 디바운스 / 코드 러너 유닛 테스트
npm run build      # 타입체크 + 프로덕션 빌드 (dist/)
```

- 웹캠은 `localhost` 또는 HTTPS에서만 열립니다.
- 포즈 모델(`pose_landmarker_full.task`, 약 9MB)은 첫 실행 때 Google 스토리지에서 받아옵니다. WASM 런타임은 Vite가 번들해서 같은 도메인에서 서빙합니다.

## 사용법

1. **📷 웹캠으로 시작** → 카메라에 전신(골반까지)이 나오게 섭니다.
2. **캘리브레이션**: 차렷 자세로 2초 유지. 이때 잰 골반 높이로 점프를 판정합니다. (건너뛰면 점프=실행 인식이 꺼짐)
3. 포즈를 **약 0.6초 유지**하면 원형 링이 차오르고, 다 차면 확정 → 플래시 + 효과음 + 토큰이 에디터에 타이핑됩니다.
4. 양팔을 몸에 붙이고 **점프**하면 실행. `Hello World`가 나오면 컨페티 🎉

같은 포즈를 계속 유지해도 한 번만 입력됩니다. 다시 입력하려면 포즈를 풀었다가 다시 하세요.

### 포즈 매핑 (토큰 모드)

| 키 | 포즈 | 동작 | 입력 |
|:-:|:-:|---|---|
| `1` | 🙌 만세 V | 양팔을 위로 쭉 뻗어 V | `console.log(` |
| `2` | 👉 오른팔 쭉 | 오른팔만 옆으로 수평 (왼팔은 아래) | `"Hello ` |
| `3` | 👈 왼팔 쭉 | 왼팔만 옆으로 수평 (오른팔은 아래) | `World"` |
| `4` | 🙅 크로스 | 양팔을 가슴 앞에서 X자로 교차 | `)` |
| `5` | 🙋 머리 위 한 손 | 한 손을 머리 위로 (다른 손은 아래) | `;` |
| `6` | 🦸 허리 손 | 양손을 허리에, 팔꿈치는 바깥으로 | ⌫ 한 글자 지우기 |
| `7` | 🚀 점프! 실행 | 양팔을 아래로 쭉 붙이고 점프 | ▶ 실행 |

"오른팔/왼팔"은 **춤추는 사람 기준**입니다. 화면은 거울처럼 좌우 반전돼 있어서, 오른팔을 들면 화면에서도 오른쪽 팔이 올라갑니다.

> 매핑은 [`src/config/poses.ts`](src/config/poses.ts)의 `TOKEN_POSES`에서, 포즈 이름/이모지/설명은 같은 파일의 `POSE_LIBRARY`에서 관리합니다. 기본 포즈의 판별 규칙과 임계값(각도 등)은 [`src/pose/classifier.ts`](src/pose/classifier.ts)의 `THRESHOLDS`에 있습니다.

### 모드 2: 미션 모드 🏆 ("춤으로 알고리즘 풀기")

목표 코드가 화면에 보이고, 춤으로 그 코드를 완성한 뒤 점프해서 실행하면 클리어. 미션마다 타이머가 돌고, 클리어 시간 순위가 브라우저(localStorage)에 저장됩니다.

1. 상단 `미션 🏆` → 미션 선택 (숫자키 `1`~`5`로도 시작)
2. `3, 2, 1, GO!` 카운트다운 후 타이머 시작
3. 에디터에 남은 목표 코드가 흐리게(고스트) 보이고, 맞게 입력한 만큼 진행률(%)이 올라갑니다. 순서가 틀리면 빨간 물결선 → 허리 손으로 지우기
4. 점프해서 실행 → 출력이 기대 출력과 같으면 **MISSION CLEAR!** (타이머 정지, 순위 저장, 신기록이면 🥇 NEW RECORD)
5. 클리어 화면: `R` 다시, `N` 다음 미션, `L` 목록

| # | 미션 | 난이도 | 기대 출력 | 포인트 |
|:-:|---|:-:|---|---|
| 1 | Hello World | ★☆☆☆☆ | `Hello World` | 토큰 모드와 같은 포즈 |
| 2 | 1부터 5까지 | ★★☆☆☆ | `1` ~ `5` | for 반복문 |
| 3 | 짝수만 출력 | ★★★☆☆ | `2 4 6 8 10` | 조건문, 토큰 순서가 섞여 있음 |
| 4 | 1부터 10까지 합 | ★★★★☆ | `55` | 누적 변수, 출력은 반복문 밖 |
| 5 | FizzBuzz | ★★★★★ | `1 2 Fizz … FizzBuzz` | 조건 순서가 틀리면 실행은 돼도 클리어 실패! |

미션 키보드: 팔레트 순서대로 `1`~`9`, `Backspace` = 지우기(허리 손), `Enter` = 실행(점프). 오른쪽 패널에 이번 미션의 포즈 → 토큰 목록과 순위표가 있습니다.

**미션 추가/수정**은 [`src/config/missions.ts`](src/config/missions.ts) 한 파일에서 합니다.

```ts
{
  id: 'count-to-5', title: '1부터 5까지', difficulty: 2,
  description: 'for 반복문으로 1부터 5까지 한 줄씩 출력하세요.',
  palette: [                                   // 이 미션에서 쓸 포즈 → 토큰 (화면에 이 순서로 표시)
    { pose: 'V_UP', text: 'for (let i = 1; ' },
    { pose: 'RIGHT_SIDE', text: 'i <= 5; ' },   // 커스텀 포즈(T_POSE 등)도 OK
    ...
  ],
  solution: ['V_UP', 'RIGHT_SIDE', ...],          // 정답 순서 → 목표 코드가 자동으로 만들어짐
  expected: ['1', '2', '3', '4', '5'],         // 이 출력이 나오면 클리어
}
```

**새 포즈 추가**: 미션에 포즈가 더 필요하면 `src/config/poses.ts`의 `POSE_LIBRARY`에 팔 각도 규칙(`rule`)만 적으면 됩니다. 분류기 코드는 건드릴 필요 없어요.

```ts
{
  id: 'DISCO_RIGHT', name: '디스코 오른손', emoji: '🕺', how: '오른팔은 대각선 위, 왼팔은 대각선 아래',
  // theta: 어깨→손목 방향. 0 = 아래, 90 = 옆으로 수평, 180 = 위, 음수 = 몸 안쪽으로 교차
  rule: { right: { theta: [125, 170], minElbow: 140 }, left: { theta: [20, 65] } },
}
```

지금 들어있는 커스텀 포즈: ✈️ 비행기 T (양팔 옆으로), 🕺 디스코 오른손, 💃 디스코 왼손, 🙆 아래 V (양팔 대각선 아래). 기본 포즈가 먼저 판정되고, 어디에도 안 걸릴 때만 커스텀 규칙을 위에서부터 검사합니다. `npm test`가 모든 미션에 대해 "정답 코드가 기대 출력을 내는지", "팔레트의 모든 포즈가 실제로 인식되는지"를 검사하니, 미션을 추가한 뒤 테스트를 돌려보세요.

### 모드 3: 수기신호 (하드모드 🔥)

깃발 수기신호(semaphore)처럼 양팔 방향 조합으로 A~Z를 한 글자씩 입력합니다. 입력한 글자는 `console.log("…");` 안에 들어갑니다.

- 양팔을 쭉 펴서 8방향(위, 대각선 위, 옆, 대각선 아래, 아래) 중 하나로 가리킵니다. 두 팔의 방향 조합 하나가 글자 하나입니다.
- 화면 오른쪽 위 **NOW** 박스에 지금 팔 각도로 읽히는 글자가 실시간으로 미리 보입니다.
- 오른쪽 패널에 전체 신호표가 있습니다 (화면에 보이는 거울 방향 기준).
- 특수 신호: 한 팔 위 + 다른 팔 대각선 위 = 띄어쓰기 `␣`, "취소" 신호(대각선 위 ↔ 반대편 대각선 아래) = 지우기 `⌫`
- 실행은 똑같이 점프.

## 촬영 / 화면

| 기능 | 방법 |
|---|---|
| 9:16 세로 레이아웃 (위: 카메라, 아래: 에디터+출력) | 상단 `9:16 릴스` 버튼 또는 `Shift+L` |
| 디버그 UI 숨기기 (녹화 모드) | `🎬 녹화 모드` 버튼 또는 `Esc` (다시 `Esc`로 복귀) |
| 미러 끄기/켜기 | `Shift+F` |
| 다시 캘리브레이션 | `Shift+C` |
| 코드 지우기 | `Shift+R` |
| 소리 끄기/켜기 | `Shift+S` |
| 모드 전환 (토큰 → 미션 → 수기신호) | `Shift+M` |

팁: 9:16 + 녹화 모드로 두고 브라우저 창을 화면 높이에 맞춘 뒤 화면 녹화하면 바로 릴스 비율로 나옵니다.

## 웹캠 없이 테스트하기

- **키보드 시뮬레이션**: 숫자키 `1`~`7` = 각 포즈. 키를 누르면 가짜 스켈레톤이 그 포즈를 취하고, 실제 분류기 → 디바운스 → 입력 경로를 그대로 탑니다. 키를 누르고 있으면 계속 유지한 것과 같습니다. 수기신호 모드에서는 `A`~`Z`, `Space`, `Backspace`, `7`/`Enter`(실행).
- **영상 파일 입력**: `🎞️ 영상 파일` 버튼으로 춤 영상을 넣으면 웹캠 대신 그 영상을 반복 재생하며 인식합니다. 미리 찍어둔 영상으로 임계값을 튜닝할 때 유용합니다.
- **유닛 테스트**: 포즈 분류기는 순수 함수(`classifyPose(landmarks, calibration)`)라서, [`src/pose/fixtures.ts`](src/pose/fixtures.ts)의 가짜 랜드마크로 테스트합니다. 위치·거리(줌) 불변성, 좌우 구분, 점프 판정, 26개 수기신호 글자 전부, 디바운스 타이밍 등을 검증합니다.

## 구조

```
src/
  config/poses.ts        ← 포즈 목록(커스텀 포즈 규칙 포함) + 토큰 모드 매핑
  config/missions.ts     ← 미션 목록 (팔레트, 정답 순서, 기대 출력)
  mission/               미션 판정, 타이머 포맷, 로컬 순위표 (순수 함수)
  pose/
    classifier.ts        순수 함수: 랜드마크 → 포즈 (몸 기준 좌표계, 각도/상대위치)
    customPoses.ts       config에서 선언한 팔 각도 규칙으로 포즈 판정
    semaphore.ts         순수 함수: 양팔 방향 → A~Z
    holdTracker.ts       0.6초 유지 확정(디바운스) 상태 머신
    calibrator.ts        차렷 2초 캘리브레이션
    fixtures.ts          가짜 랜드마크 생성기 (테스트 + 키보드 시뮬레이션)
  code/                  하이라이터, 러너(console 캡처), 타이핑 애니메이션
  components/, fx/       화면, 스켈레톤, 링, 컨페티, WebAudio 효과음
  hooks/usePoseLandmarker.ts
```

분류기는 어깨 중점을 원점, 어깨 너비를 1로 하는 **몸 기준 좌표계**에서 판정하기 때문에 카메라에서 얼마나 떨어져 있는지, 화면 어디에 서 있는지, 미러링 여부와 상관없이 동작합니다.

## Vercel 배포

백엔드가 없는 정적 사이트라서 그대로 올리면 됩니다 (`vercel.json` 포함).

**대시보드**
1. GitHub 저장소를 Vercel에서 Import
2. Framework Preset: **Vite** (자동 인식) · Build Command `npm run build` · Output `dist`
3. Deploy → `https://<프로젝트>.vercel.app` (HTTPS라서 웹캠 바로 동작)

**CLI**
```bash
npm i -g vercel
vercel          # 프리뷰 배포
vercel --prod   # 프로덕션 배포
```
